# 🧠 Brain Tumor MRI Classification Model

A deep learning model for classifying brain MRI images into four categories:

- Glioma
- Meningioma
- No Tumor
- Pituitary

## 📌 Project Overview

This project uses deep learning and computer vision techniques to classify brain MRI images into four categories.

The model was trained and evaluated using a labeled brain MRI dataset.

> This project is intended for educational and research purposes only and is not a medical diagnostic tool.

## 📊 Model Performance

**Test Accuracy: 84.38%**

**Test Loss: 0.5114**

### Classification Results

| Class | F1-Score |
|---|---:|
| Glioma | 79% |
| Meningioma | 74% |
| No Tumor | 94% |
| Pituitary | 89% |
